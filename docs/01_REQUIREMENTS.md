# Requirements

## Confirmed
REQ-001: The project develops an Android application.

## Undecided
The following must remain undecided until explicitly specified:
- Product purpose/use case
- Target user
- Phone/tablet/foldable/TV/Wear coverage
- Portrait/landscape policy
- Offline/online behavior
- Data storage
- Accounts/authentication
- MIDI/audio/camera/Bluetooth/USB requirements
- Notifications/background processing
- Accessibility requirements
- Localization
- Distribution method
- Paid/free/licensing model
- Analytics/crash reporting
- Minimum supported Android version (bootstrap currently uses API 26 provisionally)

## Requirement change rule
Confirmed requirements are changed only by an issue that records:
- previous requirement
- requested change
- reason
- impact
- verification method
